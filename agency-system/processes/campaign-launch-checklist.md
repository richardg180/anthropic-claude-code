# Campaign Launch Checklist

**Version**: 1.0
**Last Updated**: YYYY-MM-DD

Use this checklist to ensure flawless campaign launches every time.

---

## 📋 Pre-Launch (1 Week Before)

### Strategy & Planning
- [ ] Campaign brief finalized and approved
- [ ] Goals and KPIs clearly defined
- [ ] Budget allocated across channels
- [ ] Timeline and milestones confirmed
- [ ] Team roles and responsibilities assigned

### Creative Assets
- [ ] All copy written and approved
- [ ] All images created and optimized
- [ ] All videos produced and edited
- [ ] Brand guidelines followed
- [ ] Legal/compliance review complete (if required)

### Technical Setup
- [ ] Landing pages built and tested
- [ ] Forms tested (if applicable)
- [ ] Thank you pages set up
- [ ] Mobile responsive check complete
- [ ] Page load speed optimized
- [ ] SEO elements configured

### Tracking & Analytics
- [ ] UTM parameters defined
- [ ] Conversion tracking set up
- [ ] Analytics goals configured
- [ ] Tag manager implementation verified
- [ ] Tracking tested and confirmed working
- [ ] Dashboard/reporting template ready

### Ad Platform Setup
- [ ] Campaigns created in ad platforms
- [ ] Targeting configured correctly
- [ ] Ad groups/sets organized
- [ ] Bidding strategy selected
- [ ] Budget caps set
- [ ] Schedule configured
- [ ] Ad copy and creative uploaded

---

## ✅ Launch Day Checklist

### Final Pre-Launch (Morning of Launch)
- [ ] One final review of all ads/content
- [ ] Landing pages loading correctly
- [ ] All links tested
- [ ] Tracking verified one more time
- [ ] Budget verified
- [ ] Client final approval documented

### Go Live
- [ ] Activate campaigns in sequence
  - [ ] [Platform 1] - Time: _____
  - [ ] [Platform 2] - Time: _____
  - [ ] [Platform 3] - Time: _____

- [ ] Screenshot of live campaigns
- [ ] Document launch time for each channel

### First Hour Monitoring
- [ ] Check for approval (ads not rejected)
- [ ] Verify impressions are being served
- [ ] Confirm tracking is working
- [ ] Check for any errors or issues
- [ ] Monitor initial performance

---

## 🔍 Post-Launch (First 24-48 Hours)

### Performance Monitoring
- [ ] Review metrics against benchmarks
- [ ] Check actual spend vs. planned budget
- [ ] Verify conversion tracking working
- [ ] Review quality scores/relevance scores
- [ ] Check for any disapproved ads

### Technical Verification
- [ ] Landing page receiving traffic
- [ ] Forms submitting correctly
- [ ] Thank you pages displaying
- [ ] Email confirmations sending
- [ ] CRM/database receiving data

### Issue Resolution
- [ ] Address any technical problems
- [ ] Replace underperforming creative
- [ ] Adjust targeting if needed
- [ ] Fix any tracking issues
- [ ] Respond to any ad rejections

### Communication
- [ ] Send launch confirmation to client
- [ ] Share initial performance snapshot
- [ ] Set expectations for optimization period
- [ ] Schedule first review meeting

---

## 📊 First Week Optimization

- [ ] Daily performance reviews
- [ ] Pause poor performers
- [ ] Increase budget on top performers
- [ ] A/B test creative variations
- [ ] Refine targeting
- [ ] Adjust bids as needed
- [ ] Document learnings

---

## 🚨 Red Flags to Watch For

If any of these occur, take immediate action:

- **No impressions after 2 hours**: Check campaign status, budget, targeting
- **Tracking showing zero conversions**: Verify tracking setup
- **Spend rate way above/below plan**: Adjust bids or budget
- **High bounce rate on landing page**: Check page load, relevance
- **Ads rejected**: Revise and resubmit immediately
- **CPA significantly above target**: Pause and reassess
