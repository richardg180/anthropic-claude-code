# Quick Start Guide

Welcome to your Marketing Agency Command Center! This guide will get you up and running in 15 minutes.

## ⚡ First-Time Setup (15 minutes)

### Step 1: Understand the System (2 minutes)

This system helps you run a world-class marketing agency using Claude Code as your executive assistant. Everything is organized into these folders:

```
agency-system/
├── clients/          ← Manage client relationships
├── projects/         ← Track project delivery
├── campaigns/        ← Plan and execute campaigns
├── content/          ← Content calendar and production
├── strategy/         ← Strategic planning
├── processes/        ← SOPs and workflows
├── meetings/         ← Meeting notes and agendas
├── reports/          ← Performance tracking
├── templates/        ← Reusable templates
└── resources/        ← Tools and references
```

### Step 2: Set Up Your First Client (5 minutes)

1. **Copy the template**:
   ```
   cp agency-system/clients/client-profile-template.md agency-system/clients/acme-corp.md
   ```

2. **Open the file and ask Claude**:
   ```
   "Help me fill out the client profile for Acme Corporation"
   ```

3. **Add to active clients**:
   ```
   "Add Acme Corp to my active-clients.md file"
   ```

### Step 3: Create Your First Project (3 minutes)

1. **Tell Claude**:
   ```
   "Create a new project for Acme Corp's Q1 marketing campaign"
   ```

2. Claude will create the project file and populate it with the right structure.

3. **Add to active projects dashboard**:
   ```
   "Update active-projects.md to include this new project"
   ```

### Step 4: Plan Your Week (5 minutes)

1. **Ask Claude to help plan**:
   ```
   "Help me plan my week using the daily-standup and weekly-review templates"
   ```

2. **Set up your content calendar**:
   ```
   "Create a content calendar for Acme Corp for the next 2 weeks"
   ```

3. **Review what's urgent**:
   ```
   "What should I prioritize this week based on my current projects?"
   ```

## 🚀 Daily Workflow

### Every Morning (10 minutes)

1. **Open your daily standup**:
   ```
   "Update my daily-standup.md for today"
   ```

2. **Review priorities**:
   ```
   "Based on my active projects and clients, what are my top 3 priorities today?"
   ```

   ```
   "Review all my files and flag anything urgent or overdue"
   ```

## 💡 Pro Tips

### 1. Be Specific in Your Requests
Instead of: "Help with client work"
Try: "Create a campaign strategy for Acme Corp's product launch targeting B2B SaaS buyers"

### 2. Reference Files for Context
```
"Review /clients/acme-corp.md and /campaigns/q1-launch.md and update the campaign based on client preferences"
```

### 3. Ask for Frameworks
```
"What framework should I use to develop a content strategy?"
"Show me a proven approach for competitive analysis"
```

### 4. Batch Similar Tasks
```
"Review all active projects and create a status summary"
"Update all client health scores based on recent interactions"
```

### 5. Use Claude for Learning
```
"Explain the strategy behind this approach"
"Why would this tactic work better than that one?"
```
