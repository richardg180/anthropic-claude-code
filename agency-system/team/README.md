## 👥 Team Roles Quick Reference

| Role | Access | Focus |
|------|--------|-------|
| **Owner (You)** | Everything | Strategy, key accounts, growth |
| **Account Manager** | Their clients only | Client relationships, delivery |
| **Project Manager** | All projects | Execution, resources, deadlines |
| **Specialist** | Their tasks only | Quality execution |
| **Contractor** | Specific project only | Assigned work |

## 🚀 Getting Started

### Set Up Team Access
```
"Set up team access for [Name] as [Role]"
"Show me what access [Name] has"
"Create team onboarding checklist for [Role]"
```

### Team Commands
```
"Show team capacity for this week"
"Generate team performance report"
"List all team members and their roles"
"Create morning standup summary"
```

## 📊 Team Metrics to Track

- **Team Utilization**: 70-75% billable time target
- **Employee Retention**: 85%+ annual target
- **Average Performance Score**: 4/5+ target
- **Training Hours**: 40+ hours per year per person
- **Team NPS**: How happy is your team? Target 50+
