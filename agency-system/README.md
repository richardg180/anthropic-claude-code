# Marketing Agency Command Center

Welcome to your world-class marketing agency management system. This markdown-based system is designed to work seamlessly with Claude Code as your personal executive assistant and agency expert.

## 🎯 System Overview

This system helps you run every aspect of your marketing agency with excellence:

- **Client Management** - Track relationships, contracts, and deliverables
- **Project Execution** - Manage workflows and deadlines
- **Campaign Strategy** - Plan and execute marketing campaigns
- **Content Operations** - Schedule and produce content at scale
- **Performance Analytics** - Monitor KPIs and optimize results
- **Process Documentation** - Standardize operations for consistency
- **Strategic Planning** - Develop winning strategies
- **Meeting Management** - Run productive meetings with clear outcomes

## 🚀 Quick Start Guide

### Daily Workflow
1. Review `/meetings/daily-standup.md` - Start your day with priorities
2. Check `/projects/active-projects.md` - Review project status
3. Update `/content/content-calendar.md` - Track content deliverables
4. Log client interactions in `/clients/` - Maintain relationships

### Weekly Workflow
1. Run weekly review using `/meetings/weekly-review-template.md`
2. Update all active project statuses
3. Review campaign performance in `/reports/`
4. Plan next week's priorities

### Monthly Workflow
1. Complete monthly business review using `/reports/monthly-report-template.md`
2. Update client health scores
3. Review and refine processes
4. Strategic planning session using `/strategy/`

## 🔗 System Integrations

**Your markdown system connects with your favorite tools!**

This system integrates with HubSpot (CRM), Google Calendar/Outlook, and GoCardless (payments) to create a seamless automated workflow.

### What Gets Automated
- **HubSpot**: Sync client health scores, log activities, track deals, update contacts
- **Calendar**: Auto-create events for deliverables, log meetings, set renewal reminders
- **GoCardless**: Track payments, update financial health, alert on issues, calculate MRR

### Quick Setup
```
"Set up HubSpot integration"
"Connect my Google Calendar"
"Configure GoCardless payment tracking"
"Run morning routine automation"
```

See **[`/integrations/README.md`](integrations/README.md)** for complete setup guides and automation workflows.

### Automated Workflows
Once set up, your system automatically:
- **Morning Routine** (8 AM daily): Check payments, sync calendar, brief you on the day
- **Failed Payment** (real-time): Alert, update health, create tasks, draft communication
- **Weekly Review** (Monday 9 AM): Update all health scores, draft client emails, create action plan
- **Meeting Complete**: Log notes, update health, create tasks, sync to HubSpot
- **Client At-Risk**: Create recovery plan, schedule intervention, alert team

**No more manual data entry. Your markdown files stay the source of truth while everything syncs automatically.**

- Update project statuses weekly minimum

### 2. Use Templates Consistently
- Start with templates for repeatable tasks
- Customize as needed but maintain structure
- Document process improvements

### 3. Leverage Claude Code's Strengths
- **Strategic Thinking**: Ask for analysis and recommendations
- **Content Creation**: Draft proposals, briefs, and copy

- **Data Analysis**: Interpret metrics and identify trends

### 4. Document Everything

### 5. Regular Reviews
- Daily: Priority check and task planning

## 🎓 Pro Tips for Maximum Effectiveness

1. **Be Specific**: "Help me create a LinkedIn campaign for B2B SaaS targeting CTOs" beats "help with social media"

2. **Provide Context**: Share relevant files, past campaigns, or client preferences for better assistance

3. **Iterate Together**: Start with a draft, refine together, and document what works

4. **Ask for Frameworks**: "What framework should I use for [task]?" - Claude knows proven methodologies

5. **Request Analysis**: Share data or content and ask for professional critique and recommendations

6. **Use for Learning**: "Explain the strategy behind this approach" to continuously improve your skills

7. **Batch Similar Tasks**: "Review all client proposals in /projects and flag any issues"

8. **Create Custom Workflows**: Ask Claude to help design processes specific to your agency's needs
