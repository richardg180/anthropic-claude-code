# Project Management System

Track and manage all agency projects with clarity and precision. Every project should have its own dedicated file for complete visibility.

## 📋 Overview

- **Active Projects**: Track in `active-projects.md`
- **Project Files**: Individual files named `[project-slug].md`
- **Templates**: Use `project-template.md` for new projects
- **Archive**: Completed projects move to `/projects/archive/`

## 🎯 Project Lifecycle

### 1. Project Initiation
- Create project file from template
- Add to `active-projects.md`
- Define scope, timeline, and deliverables
- Assign team and resources
- Link to client file in `/clients/`

### 2. Project Execution
- Update status weekly (minimum)
- Track milestones and deliverables
- Log risks and issues as they arise
- Communicate progress to stakeholders

### 3. Project Delivery
- Complete all deliverables
- Gather client feedback
- Document results and learnings
- Update client profile with outcomes

### 4. Project Closure
- Conduct post-mortem review
- Archive project file
- Update templates/processes with learnings
- Celebrate wins with team

## 📊 Project Status Definitions

- 🟢 **On Track** - Meeting deadlines, within budget, no blockers
- 🟡 **At Risk** - Minor delays, budget concerns, or issues that need attention
- 🔴 **Blocked** - Significant delays, major issues, requires immediate action
- ⚫ **On Hold** - Paused by client or internal decision
- ✅ **Completed** - Delivered and accepted
- ❌ **Cancelled** - Project terminated before completion

## 💡 How to Use Claude Code

### Project Creation
```
"Create a new project for [Client Name]'s [Campaign/Initiative]"
"Set up project tracking for our Q2 website redesign"
```

### Project Management
```
"Update status for all active projects"
"Flag any projects at risk of missing deadlines"
"Generate a project summary for stakeholder review"
```

### Project Analysis
```
"Review project profitability for [Project Name]"
"Analyze what went wrong with [Project] and suggest improvements"
"Create a timeline for [deliverables]"
```

### Resource Planning
```
"Show me team capacity across all projects"
"Identify resource conflicts for this week"
"Calculate estimated hours needed for [scope]"
```

## 🎯 Best Practices

1. **Update Frequently** - Weekly status updates minimum
2. **Flag Issues Early** - Don't wait for problems to escalate
3. **Document Decisions** - Record why choices were made
4. **Track Time** - Monitor actual vs estimated hours
5. **Communicate Proactively** - Keep stakeholders informed
6. **Learn from Each Project** - Document wins and lessons
