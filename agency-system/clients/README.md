# Client Management System

This directory contains all client-related information for your agency. Each client should have their own markdown file with comprehensive details.

## 📋 Quick Reference

- **Active Clients**: Listed in `active-clients.md`
- **Client Profiles**: Individual files named `[client-slug].md`
- **Prospect Pipeline**: Track potential clients in `prospects.md`
- **Client Health**: Monitor account health in `client-health-dashboard.md`

## 🎯 Client Management Workflow

### Onboarding New Clients
1. Create new client file from `client-profile-template.md`
2. Add to `active-clients.md`
3. Schedule kickoff meeting in `/meetings/`
4. Create initial project in `/projects/`
5. Document strategy in `/strategy/`

### Maintaining Client Relationships
- Log all significant interactions in client file
- Update client health score monthly
- Review deliverables and satisfaction quarterly
- Document preferences and feedback continuously

### Offboarding Clients
1. Complete final deliverables
2. Conduct exit interview
3. Archive client file to `/clients/archive/`
4. Document lessons learned
5. Update in `active-clients.md`

- Revenue growth
