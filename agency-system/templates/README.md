# Reusable Templates

Quick-access templates for common agency tasks and deliverables.

## 📋 Overview

This folder contains reusable templates that don't fit into other specific categories. These templates help you work faster and maintain consistency.

## 🎯 Available Templates

### Communication Templates
- Client welcome emails
- Project kickoff emails
- Status update emails
- Proposal follow-ups
- Contract renewal reminders

### Proposal Templates
- Service proposals
- Pricing templates
- Scope of work documents
- Statement of work (SOW)

### Presentation Templates
- Client pitch decks
- Strategy presentations
- Results presentations
- Quarterly business reviews

### Planning Templates
- Editorial calendars
- Campaign timelines
- Project roadmaps
- Budget planning sheets

## 💡 How to Use Claude Code

### Template Creation
```
"Create a proposal template for [service type]"
"Draft an email template for [situation]"
"Design a presentation outline for [purpose]"
```

### Template Customization
```
"Adapt this template for [specific client/situation]"
"Personalize this email for [client name]"
"Update this template based on recent feedback"
```

### Template Management
```
"Review all templates and identify which need updating"
"Create a new template based on [recent successful deliverable]"
```

## 🎯 Best Practices

1. **Keep Templates Current** - Review quarterly
2. **Customize Before Sending** - Never send generic
3. **Test Templates** - Make sure links, formatting work
4. **Version Control** - Track changes to templates
5. **Share Successes** - Turn wins into templates

---

Use these templates to work smarter, not harder.
